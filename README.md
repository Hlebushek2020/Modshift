# 🔄 Modshift (В разработке / Черновой вариант)

⚠️ **ВНИМАНИЕ:** Этот документ описывает концепт и плановую архитектуру приложения. Настоящее описание не отражает реальность на 100%, так как продукт находится на этапе проектирования и разработки чернового варианта.

---

**Modshift** — это удобная программа для игроков, владельцев серверов и создателей модпаков в Minecraft, которая поможет навести порядок в папке с модами и безопасно перенести её на свежие версии игры.

Если вы хоть раз пытались перевести свою сборку модов со старой версии (например, 1.20.1) на новую (например, 1.21.1), то знаете, какая это головная боль. Нужно вручную искать каждый мод в интернете, проверять совместимость и заново перенастраивать файлы конфигураций (конфиги). **Modshift** создается для того, чтобы автоматизировать этот процесс.

Программа планируется в двух вариантах: графическое приложение с окнами для обычных пользователей (`Modshift.Gui`) и консольная утилита для работы через терминал (`Modshift.Cli`).

## 🎯 План выпуска версий

### 🚀 Первая версия (MVP) — Только миграция
Первый релиз будет сфокусирован исключительно на одной главной задаче — **переносе существующей сборки на более новую версию игры**. В первой версии будет реализовано:
*   **Окно создания сборки:** Отдельное окно, где вы вводите название сборки, указываете путь к вашей папке модов, а программа мгновенно выводит плоский список файлов и определяет текущую версию игры.
*   **Ручной запрос к API Modrinth:** Программа не лезет в сеть сама. Только по вашей кнопке она отправляет хэши файлов в интернет и открывает отдельное окно результатов. Там моды автоматически разделяются на два уровня: основные контентные моды и технические библиотеки, которые им нужны для работы. Вы можете принять или отклонить эти изменения.
*   **Мастер миграции с шагами:** Пошаговое окно переноса сборки. Вы выбираете новую версию Майнкрафта и лоадер (Fabric/Forge/NeoForge), видите древовидную таблицу совместимости модов и запускаете процесс.

### 🔄 Вторая версия — Менеджмент и Обновления
После обкатки движка миграции в программу будут добавлены все остальные запланированные функции:
*   **Скрытый запуск Java (Headless-режим):** Программа на пару секунд запускает фоновый процесс игры/сервера для создания чистых файлов настроек под новую версию, а затем сравнивает их с вашими старыми файлами (JSON/TOML) и аккуратно переносит ваши личные параметры, ничего не ломало.
*   **Обновление модов:** Возможность обновлять моды до актуальных версий, оставаясь на текущей версии игры.
*   **Заметки и комментарии:** Возможность писать текстовые примечания прямо напротив любого мода в таблице (например: *«Не обновлять, ломает шейдеры»*).
*   **Заморозка (Pinned):** Кнопка, запрещающая автоматике трогать или обновлять выбранный мод.
*   **Привязка конфигов:** Возможность вручную привязывать конкретные файлы настроек к их родительским модам для более точного контроля.
*   **Полный CRUD модов:** Кнопки для быстрого добавления новых `.jar` файлов в таблицу и физического удаления ненужных модов с диска через интерфейс программы.
